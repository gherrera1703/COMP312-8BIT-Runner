# COMP 312 - 8-Bit Runner

An open-source 2D platform runner developed in Unity for COMP 312:
Open Source Computing at Loyola University Chicago.

## Developers

- Giancarlo Herrera
- Shu Perez

## About

8-Bit Runner is a simple pixel-art platform game where the player
runs through levels, jumps across platforms, avoids hazards and
enemies, and collects items to increase their score.

## Planned Features

- Player movement and jumping
- 8-bit / pixel-art graphics
- Platforming levels
- Collectibles
- Enemies and hazards
- Score system
- Main menu
- Game-over screen
- Sound effects and music
